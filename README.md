# Katrin Luxe Locks — сайт

Статический сайт (HTML + CSS + JS, без сборки). Открывается двойным кликом по `index.html`
или через любой статический хостинг (GitHub Pages, Netlify, Vercel).

## Что нужно заполнить (js/main.js, вверху файла)

```js
const CONFIG = { whatsapp: '', telegram: '', instagram: '', endpoint: '' };
```

- `whatsapp` — номер цифрами, например `995555123456`
- `telegram`, `instagram` — username без `@`
- `endpoint` — (необязательно) URL приёмника форм (Formspree и т.п.)

Пока поля пусты, кнопки соцсетей ведут к форме записи, а отправка заявки открывает выбор получателя в мессенджере.

## Языки

Сайт на 4 языках: английский (по умолчанию), русский, турецкий, грузинский.
Переключатель — в шапке; выбор запоминается. Ссылка на нужный язык: `?lang=ru`, `?lang=tr`, `?lang=ka`.
Все тексты — в `js/i18n.js` (по одному блоку на язык). Грузинский и турецкий переводы желательно показать носителю языка.

## Что заменить на реальное

- `data.reviews` в `js/i18n.js` — **примеры отзывов**, замените на реальные (во всех 4 языках).
- `STORIES` / `GALLERY` в `js/main.js` — пары фото «до/после»; подписи к ним — в `js/i18n.js`.
- `data.services` в `js/i18n.js` — время и сроки носки ориентировочные, поправьте под реальные.

## Фото

Фото моделей в первом экране, в Hair Lab (девушка со спины) и в блоках «Обо мне», «Услуги», «Запись» подключены с Unsplash (бесплатная лицензия Unsplash, разрешено коммерческое использование). Фото работ Катрин лежат в `assets/img/`.

## Видео

`assets/video/` — сжатые промо-ролики (оригиналы лежат в папке проекта):
- `showreel.mp4` (Видео 2) — блок-шоурил после первого экрана; на телефоне фоном играет лёгкая `showreel-sm.mp4` без звука;
- `process.mp4` (Видео 1) — в разделе «Как это проходит»;
- `capsules.mp4` (Видео 3, реальная работа Катрин) — улучшено: шумоподавление, плавное замедление ×2, апскейл до 1080×1920, цветокоррекция, резкость. Блок «Капсулы, которых не видно» в разделе «Работы»; на телефоне — `capsules-sm.mp4`. Кадр из него — в карточке «Капсульное наращивание».
Кнопки «Смотреть со звуком» открывают ролик в полноэкранном окне. Кадры из роликов используются в карточках услуг (`svc-*.webp`), обложках видео (`poster-*.webp`) и фоне записи (`book-bg.webp`).

## Структура

```
index.html
css/style.css
js/main.js
js/i18n.js   — переводы (en, ru, tr, ka)
js/hair.js   — реалистичная визуализация волос для Hair Lab
assets/img/   — фото работ, портреты, логотип, кадры из роликов (webp)
assets/video/ — промо-ролики (mp4)
assets/favicon.png, apple-touch-icon.png
```
